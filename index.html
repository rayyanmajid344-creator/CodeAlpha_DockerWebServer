This page is served by Nginx from inside a Docker container. Nginx fills in the container plate each time the page loads, so refreshing updates the time, and a new container shows a new ID.

Try the container lifecycle

Run these in a terminal and refresh this page after each one to see what changes.

  1. docker stop webserverThe page stops loading. The container still exists; it just isn't running.
  2. docker start webserverThe same container starts again, so the plate shows the same ID.
  3. docker logs webserverEvery visit to this page appears in Nginx's access log.
  4. docker rm -f webserverThe container is deleted. The image it was made from stays.
  5. docker run -d -p 8080:80 --name webserver my-webserverA brand new container from the same image, so the plate shows a new ID.

Docker checks this container's health every 30 seconds by calling /health. Run docker ps to see the result in the status column.
